# Working-slice acceptance

The first delivery gate toward the CAD feature set is a working single-part slice, following the milestone order in `AGENTS.md`. It is **not complete** when a native primitive can be built or the addon can be imported. The reference bracket workflow now passes that gate with the limitations below; passing it does not complete the broader CAD module. Assemblies and broader modelling tools are later CAD capabilities. CAM, FEA and CFD are separate modules, excluded from the current CAD scope.

## Current state and next dependencies

1. **Bootstrap:** CMake targets, bindings, addon packaging and build documentation exist. Linux runtime libraries/resources, manifests, notices and source/relink companions are packaged through CMake. Relocation checks mask host OCCT and test missing-library failure. Cross-platform/older-distribution portability and final release licensing/provenance review remain outside that evidence; see [runtime packaging](runtime-packaging.md).
2. **Core foundation:** stable IDs, basic unit-tagged parameters, persistent sketches/features/references, versioned snapshots/migration, PlaneGCS and OCCT services exist. Feature evaluation owns cached bodies, diagnostics, last-valid displays and current-result/export guards. Extrusion/subtraction, suppression, rollback and dependency-checked reorder/deletion work through native APIs. Construction/Boolean provenance and explicit named-reference repair now exist; fillets consume persistent edge targets with generated-boundary provenance; broader naming coverage remains pending. OndselSolver belongs to the later assembly adapter and is not required for single-part acceptance.
3. **Solid integration:** managed hosts, bulk semantic display maps, face/edge/vertex selection and GPU highlights exist. Exact B-rep rays, trimmed closest points, kernel measurements and persistent-reference capture are connected to current picks. Whole-body materials, duplication/deletion/conversion, focused guards, load and undo/redo have checks. Host-owned static viewport/render visibility, per-ViewLayer hiding, collection moves/exclusions and local view now have a presentation-only adapter. The standard-workspace event test covers all selection domains, perspective picks, GPU draws, references and command undo. Animated render visibility, interactive render-thread acceptance, interactive dragging/gizmos, broader entry-point coverage and difficult curve/screen candidate cases remain; see [selection/queries](selection-and-queries.md), [Solid integration](solid-integration.md) and [entry-point audit](solid-operation-audit.md).
4. **Parametric modeling:** native sketch solving and extrusion/subtraction/history foundations exist. Blender numeric rectangle creation, depth/dimension editing, parameter-bound sketch dimensions and directed parameter expressions with unit validation/cycle detection exist. Initial viewport line/circle/rectangle drawing, constraints, point/dimension dragging, detached confirm/cancel previews and sketch extrusion/cut dialogs now exist. Constant-radius edge fillets, literal/parameter radius editing, explicit input repair and sidebar history controls now exist. Add associative face-based sketch placement, a full sketch toolbar/gizmos and solid feature previews. Preserve CAD topology references or expose explicit repair diagnostics rather than silently changing the selected region.
5. **Reference acceptance:** verified. A constrained L-profile bracket with perpendicular through cuts and a persistent constant-radius fillet is constructed through Blender commands and real modal mouse/key events at small-mechanical, ordinary and furniture scales. Checks cover earlier parameter edits, undo/redo, save/reopen, failure/blocked dependents, material retention, Cycles renders, analytic STEP readback and precise through-hole rays without relaxing the 0.001 mm budget. Actual addon installation/enable and separate-process preference-based activation edit/export the saved bracket offline. This is evidence for the defined reference workflow, not unrestricted CAD acceptance; see [bracket acceptance](bracket-acceptance.md) and [STEP export](step-exchange.md).

## Remaining CAD work

- Complete transactional solid feature previews, interactive handles and sketch toolbar/gizmo coverage.
- Add persistent face-attached sketch placement; current arbitrary planar frames are explicitly positioned, not associative.
- Add STEP import as a persistent document definition, then expand profile-region and additive-solid workflows with explicit semantics.
- Extend topology/reference coverage and repair, selection robustness and the documented Blender operation/rendering integration gaps.
- Treat assemblies and broader CAD tools as subsequent independently scoped CAD capabilities, not prerequisites for the verified reference bracket. Their remaining scope is too broad for a defensible completion percentage or fixed time estimate.

Each completed capability must have durable documentation and proportionate verification before integration. Native geometry checks are evidence only for the kernel-service boundary; they do not stand in for the interactive bracket workflow.
